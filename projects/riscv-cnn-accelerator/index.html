01 / OVERVIEW

One FPGA system, from model data to a visible result.

The project explores hardware/software co-design: convolution runs in a dedicated RTL accelerator while the processor and bare-metal firmware coordinate data movement, later CNN stages, and output. The goal is not only a working demo, but a traceable path from integer reference data to hardware behavior.

04 / VERIFICATION

Check small pieces, then check the whole system.

The verification approach combines module-level directed tests with integer reference data and firmware-driven integration. This helps distinguish arithmetic errors from interface, sequencing, or data-movement failures.

  • Directed RTL tests for processor and accelerator behavior.
  • Integer golden-data comparison for CNN layer outputs.
  • SDHC simulation model for the raw-sector storage path.
  • Firmware/RTL co-simulation and end-to-end hardware regression.
Team attribution: the repository and report document a three-person implementation. Individual module ownership is not claimed where the source material does not provide an auditable responsibility breakdown.
