02 / FEATURED PROJECT

RISC-V Controlled INT8 CNN Accelerator on FPGA

A complete team-developed inference system, documented from architecture and RTL through firmware, verification, place-and-route, and board demonstration.

HARDWARE DEMOTANG NANO 20K · 2026
PROJECT / 01

RV32I + 4×4 PE array + microSD + HDMI

Conv1 and Conv2 run in a signed-INT8 RTL accelerator. Bare-metal RV32I firmware performs pooling, requantization, FC1, FC2, and Argmax while coordinating raw-sector microSD data and result publication.

  • 1,016,064 convolution MACs per inference
  • 16 parallel INT8 multiply-accumulate lanes
  • 98/100 included real handwritten samples classified by the exported integer pipeline
  • CRC32-protected UART loading for separate IMEM and DMEM
